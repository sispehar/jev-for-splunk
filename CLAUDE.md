# Working in this repository

One Splunk app, `jev_for_splunk`: the `| jev` search command. The TypeSafe docs
(docs.typesafe.ai/llms.txt) are the source of truth for Jev.

## Layout
- `jev_for_splunk/bin/jev_core/`: standard library only. Never import splunklib there (a test enforces
  it). splunklib code lives in `bin/jev.py`, `bin/jevtest.py`, `bin/jevpurge.py` and `bin/jev_splunk.py`;
  `bin/jev_key.py` is the key endpoint, run by splunkd.
- Everything that ships runs on Python 3.9 and 3.13 (Splunk 10.0 and 10.1 bundle only 3.9).
- `bin/lib/splunklib` is vendored by `scripts/build.sh` and gitignored.

## Generated files
- `default/data/ui/views/jev_health.xml` and `default/data/ui/nav/default.xml` are generated by
  `scripts/gen_dashboards.py`. Never edit the generated files.
- `static/appIcon*.png` are drawn by `scripts/gen_icons.py` (needs Pillow; not part of the build).
  `static/` may hold only PNG and TXT files, no subdirectories (AppInspect).

## Rules
- Views never name an index; macros do. No `| rest`, no real-time windows. `tests/content` enforces this.
- **The cache key is a contract.** It is sha256 over the requested model, the canonical state and the
  canonical question, without the question id. `PRIMITIVE_TEMPLATE` is frozen.
- Everything that calls the TypeSafe API ships disabled. The one scheduled search, the nightly
  `| jevpurge`, only deletes expired cache entries.
- The key endpoint (`restmap.conf [script:jev_key]`) always requires `use_jev`: it hands out the TypeSafe
  key. `tests/content` enforces it.
- `check_for_updates` stays false. The app ships from GitHub; the Splunkbase app with the id
  `jev_for_splunk` is someone else's, and Splunk would offer its releases as updates.
- Commit only when asked. Keep commit messages free of AI attribution.

## Commands
```bash
uv run --python 3.9 --no-project --with pytest pytest -q     # and 3.13
./scripts/build.sh --appinspect                              # tests, AppInspect, dist/jev_for_splunk.tar.gz
```

Releases are GitHub releases: pushing a `v*` tag makes CI publish the package (`docs/releasing.md`).
